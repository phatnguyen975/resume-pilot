# Interview Guide

Choose questions that resolve a real gap. Use the human's language and existing answers; this is a reference, not a mandatory questionnaire.

## Context and Contact

- Occupation, target role, career stage, application market and audience; optional JD.
- CV content language and appropriate page target.
- Preferred name, city/country and professional email; optional phone and relevant links.
- What existing CV, portfolio, work sample or document may the agent read?

Do not default to GitHub or require a portfolio. Avoid unnecessary sensitive details such as ID number, birthdate, marital status or full home address.

## Relevant Experience

Start with the strongest available evidence: employment, placements, study, projects, practice, research, independent work or community activity.

Ask about context/organization, role, dates, personal responsibilities, actions and outcomes. Separate team results from individual contribution. Ask how numbers were measured and over what period; use accurate qualitative outcomes when no verified metric exists.

| Field/context                 | Follow-ups only when relevant                                                |
| ----------------------------- | ---------------------------------------------------------------------------- |
| Operations, sales, service    | Process changes, customer work, campaigns, service quality, responsibilities |
| Education, community work     | Teaching/training, programs, audiences, materials and contributions          |
| Research                      | Question, methods, role, publications, authorship and confirmed identifiers  |
| Design, communication         | Brief, audience, deliverables, portfolio ownership and contribution          |
| Software, technical work      | Features, tools actually used, decisions, tests and releases                 |
| Early career or career change | Coursework, placements, transferable skills and independent work             |

Never require client, patient, student or employer-confidential data as proof. Human confirmation can be recorded without uploading confidential artifacts.

## Education and Skills

- Institution, qualification, field and dates; optional relevant coursework or GPA.
- Occupational skills, methods, tools and transferable skills with concrete examples.
- Credentials: exact title, issuer and date/status when relevant. Do not assume a course grants a license or an expired credential is current.
- Languages, awards, publications and volunteering only when real and useful.
- Distinguish direct tool use from mere presence in an artifact.

## Uncertainty and Presentation

Summarize confirmed facts and resolve ambiguities. Keep optional missing details out; track important questions. Never invent dates, seniority, metrics or proficiency.

Offer the theme gallery and ask for theme, CV language and page target before review. On updates ask whether to retain existing preferences. Use the full snapshot for approval, not a sequence of implied approvals.
